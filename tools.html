Tools & platforms

A curated directory of tools, SDKs, and platforms in the agentic buying ecosystem — what they do and which protocols they speak.

Updated 20 August 2026 · the 20 August refresh re-checked the AdCP release lines, the AAMP component tags, the membership figure, and the agent registry; every other claim carries the date it was last verified in its own source line

Claims are badged by evidence strength; unbadged statements are verified against their cited source.

  • shipped released or in production
  • announced committed, not yet shipped
  • reported secondary sources only, or disputed
  • speculative interpretation, not settled fact

How to read this directory

Entries are grouped by what a practitioner would reach for: the specifications and software development kits (SDKs) that implement a protocol, the supply-side tools a publisher or SSP deploys to sell through an agent, the buy-side platforms and agents that buy through one, and the Model Context Protocol (MCP) servers that ad platforms have published for their own APIs. Each entry says what the tool does and which protocol it speaks — AdCP (Ad Context Protocol), AAMP (Agentic Advertising Management Protocols), or MCP alone. Listing is not endorsement, and the directory covers only tools for which a dated public source was found.

Some sources cited below were verified through search-index summaries rather than direct fetches, because the publishers returned HTTP 403 or timed out for the research agent; each such claim was cross-checked against at least one further source. As of the August 4, 2026 check that applies to ppc.land, iabcanada.com, sigma.software, and businesswire.com; iabtechlab.com and prnewswire.com, which were previously blocked, were read directly.

Protocol implementations & SDKs

  • AdCP specification repository

    The AdCP specification and its reference material. The spec spans seven negotiation surfaces — Media Buy, Creative, Signals, Accounts, Governance, Brand, and Sponsored Intelligence — plus the Trusted Match Protocol (Context Match and Identity Match) for serve-time execution, with tasks carried over MCP or Google's Agent2Agent (A2A) transport. It is licensed Apache 2.0 with express patent grants, and spec governance is deliberately separated from implementation — the sell-side reference implementation is listed under supply-side tools below. The latest tagged release is v3.1.16 (August 19, 2026) on a weekly-plus cadence; implementers targeting the 3.1 line are directed to 3.1.2, since 3.1.3 was withdrawn. announced A v3.2.0-beta.0 pre-release opened a 3.2 line on August 17, 2026 and had reached beta.3 by August 19; there is no stable 3.2 release to build against yet.

    Source: AdCP GitHub repository; AdCP GitHub releases; AdCP CHANGELOG.md; AdCP documentation · last verified 2026-08-04, except the v3.1.x release line and the 3.2 pre-releases, verified 2026-08-20

  • AAMP protocol repositories

    IAB Tech Lab publishes AAMP as a set of independently versioned open-source repositories: Agentic Direct (core communication and orchestration), Buyer Agent, Seller Agent, Registry Agent, the Agentic Real Time Framework, Agentic Audiences, iab-agentic-primitives (a shared contract library), and agentic-mobile. Release tags continued into August 2026 — seller-agent v2.4.1 on August 5, buyer-agent v2.4.1 and iab-agentic-primitives v0.5.1 on August 10, and both agents at v2.4.2 on August 18 — and licensing is mixed across repositories: most are Apache 2.0, the Agentic Real Time Framework is AGPL v3, Agentic Audiences carries a non-standard license declaration, and the registry example carries none. reported Those tags sit above AAMP 2.3, but no IAB Tech Lab announcement names an "AAMP 2.4," so a component tag is not the same thing as an announced protocol version.

    Source: AAMP GitHub repository; IABTechLab agentic repositories · last verified 2026-08-04; the August release tags verified 2026-08-20 from the buyer-agent, seller-agent, and iab-agentic-primitives release feeds

  • AAMP Buyer & Seller Agent SDKs

    Transaction-ready SDKs that let a buyer agent and a seller agent negotiate, exchange rate cards, and execute programmatic deals with audit trails and human-approval guardrails. They are built on OpenDirect 2.1, incorporate AdCOM, and integrate with OpenRTB and Prebid; the same release added an Agentic Audiences OpenRTB extension, a Prebid module, and an open-source scorer. They shipped in AAMP 2.0. Sources conflict on that release date: IAB Tech Lab and LexisNexis coverage indicate April 2026, while one secondary source says June; April is the better-sourced date. reported

    Source: IAB Tech Lab; LexisNexis · last verified 2026-08-04

  • Agentic Real Time Framework (ARTF)

    AAMP's real-time bidding component, written in Rust and published under AGPL v3. It was released as ARTF v1.0 for public comment on November 13, 2025, with the comment period extended to January 15, 2026. announced IAB Tech Lab has claimed that a containerized, same-data-center architecture can cut bid request-response latency by up to roughly 80% (from 600–800 ms to about 100 ms); that figure is a vendor performance claim and has not been independently benchmarked.

    Source: IABTechLab agentic repositories; PR Newswire; MarTech · last verified 2026-08-04

Supply-side tools & sell-side agents

What a publisher, ad server, or SSP (supply-side platform) would deploy to make inventory available to buying agents. Both protocol families place the sell side behind an agent that answers discovery requests and confirms deals, so the tools here are servers and agent implementations rather than dashboards.

  • Prebid Sales Agent

    The reference implementation of AdCP's sell-side, maintained by the Prebid community rather than by the standards body — AdCP separates spec governance from implementation by design. Its documentation states that the Sales Agent is built on AdCP and describes it as a server exposing inventory to AI agents over MCP and A2A, integrating with ad servers such as Google Ad Manager. Publishers can run it locally to evaluate it or deploy their own instance, so it is the starting point for a publisher or SSP standing up an AdCP sales agent.

    Source: Prebid Sales Agent documentation; Prebid; AdCP GitHub repository · last verified 2026-08-04

  • DanAds & Sigma Software Sales Agent for Publishers

    A seller agent built natively on AdCP, launched June 24, 2026, that maps DanAds' existing inventory taxonomy, packaging logic, and permissions onto AdCP primitives so a publisher can expose existing inventory to buying agents without changing its workflows. It launched with theScore and RTL AdAlliance, and RTL AdAlliance put a seller agent on its AdManager platform giving agents access to its European Total Video inventory.

    Source: ExchangeWire · last verified 2026-08-04

  • FreeWheel agentic server

    The sell-side server FreeWheel built for the agentic buys announced on January 6, 2026 with NBCUniversal, agency RPA, and Newton Research, in which buy-side agents negotiated with sell-side agents over MCP across premium video — including live football playoff linear inventory. reported Whether it is specifically an AdCP server rests on secondary coverage: the NBCUniversal announcement names only MCP.

    Source: NBCUniversal; Adgentek statistics (the AdCP attribution) · last verified 2026-08-04

  • Swivel seller agent

    The seller agent on the other side of the first agent-to-agent media buy: a Scope3 buyer agent transacted LG Ads programmatic inventory against it, with real money changing hands and two humans approving. reported Sources place the buy on October 15 or 16, 2025.

    Source: MediaPost; adcontextprotocol.org · last verified 2026-08-04

  • AAMP Seller Agent

    The sell-side half of AAMP's transaction-ready SDK pair: it publishes rate cards and confirms deals against a buyer agent, built on OpenDirect 2.1 with AdCOM, audit trails, and human-approval guardrails. AAMP 2.3 added a pricing-provenance field so an agent cannot invent a price it was not given.

    Source: IAB Tech Lab; PPC Land; AAMP GitHub repository · last verified 2026-08-04

  • AAMP Agent Registry

    AAMP's agent-discovery and transparency component: how a buying agent finds the sell-side agents it can transact with. It sits under the framework's Trust and Transparency pillar, and IAB Tech Lab states that the registry is open to members and non-members alike and free for anyone to sign up and register. Note the distinction between the service and the code: the public repository is published as a registry agent example and carries no license. PMG's integration is the production use of the registry documented here.

    Source: IAB Tech Lab; IABTechLab agentic repositories; PR Newswire (PMG) · last verified 2026-08-04

  • AgenticAdvertising.org agent registry

    The AdCP side's equivalent directory: a public registry of sales, creative, and signals agents that implement AdCP, filterable by agent type, status, and compliance. Its public API returned 30 registered agents on August 20, 2026 — 25 sales, three signals, one creative, and one buying agent — so it is a useful map of the sell side and close to silent on the buy side. The two protocol families each run their own registry; no shared or federated registry between them is documented.

    Source: AgenticAdvertising.org — agent registry; AdCP registry API · last verified 2026-08-20

  • Publishers & sell-side platforms in the AdCP coalition

    AdCP launched from a largely supply-side coalition: Yahoo, PubMatic, Scope3, Optable, Swivel, and Triton Digital (audio) founded it in October 2025. reported Members named across later coverage include Magnite, Samba TV, The Weather Company, LG Ad Solutions, Raptive, and Affinity, which joined to bring OEM and browser inventory into the standard. Treat this as a membership list, not a deployment list — see the gaps note below.

    Source: Triton Digital; Samba TV; PPC Land; Adgentek statistics · last verified 2026-08-04

Buy-side platforms & agents

Except where an entry says otherwise, the coverage documenting these deployments names the agent or platform without stating which protocol it uses, so protocol support should not be inferred from a company's membership in either standards body.

  • Kochava StationOne "IAB Workspace"

    An open-source workspace that integrates the AAMP Buyer Agent SDK, announced March 24, 2026 with an open beta in the first and second quarters of 2026. It lets buyers run standards-compliant agentic workflows against OpenDirect 2.1 without committing real spend — a sandbox rather than a live-spend environment.

    Source: GlobeNewswire; PPC Land · last verified 2026-08-04

  • PubMatic AgenticOS

    PubMatic's agentic platform, and the buy-side environment with the most AdCP evidence attached to it. PubMatic and agency Butler/Till ran an AdCP-enabled agentic connected-TV campaign for the Clubtails brand announced December 15, 2025 — planned, executed, and optimized by agents with no demand-side platform workflow and no manual optimization desk — with PubMatic describing AdCP as the protocol carrying agent-to-system communication. Optable's Audience Agent was then integrated into AgenticOS in March 2026, with activation running through PubMatic Activate. In August 2026 PubMatic added a five-step guardrail framework for buying agents: permission boundaries, business rules, pre-approved asset libraries, human approval through one-time passcodes, and audit trails with drift detection. It was piloted with Rise, a Quad agency, alongside the existing AgenticOS partners Optable and AdRoll.

    Source: PubMatic; PPC Land; MediaPost · last verified 2026-08-04; the guardrail framework from MediaPost and PPC Land · last verified 2026-08-18

  • InMobi Buyer Hub

    InMobi Advertising's self-serve deal platform, to which it added a conversational AI agent for media buyers on August 13, 2026. The same announcement opened Buyer Hub to agencies and managed-service demand-side platforms with role-based access controls. The coverage located does not state which agentic protocol the agent uses.

    Source: Business Wire · last verified 2026-08-18

  • Horizon Media Blu — agentic orchestration layer

    An agentic orchestration layer inside Horizon Media's Blu platform, launched June 18, 2026 for real-time cross-channel media decisioning with human oversight. The release names testing partners including Disney, Fox, NBCUniversal, TikTok, Databricks, Innovid, Magnite, Kochava, iHeartMedia, and Snap. It describes partner integration over APIs and MCP-standard interfaces and names neither AdCP nor AAMP, so this is an orchestration layer entry rather than a protocol implementation.

    Source: PR Newswire; MediaPost; Adweek · last verified 2026-08-18

  • Optable Audience Agent

    An agent that lets buying agents discover, build, and activate publisher and data-owner first-party audience signals without the underlying data being exposed or transferred. Integrated into PubMatic AgenticOS in an announcement dated March 12, 2026, which the two companies position as an early live example of AdCP running across production programmatic infrastructure. Optable is one of AdCP's six founding members.

    Source: PPC Land; Optable · last verified 2026-08-04

  • PMG Alli

    PMG's own operating system, into which the agency integrated AAMP's Buyer Agent architecture, Sub-Agent architecture, and Agent Registry, announced April 7, 2026. IAB Tech Lab describes Alli as used across PMG to manage media buying, integrate data providers, and coordinate with demand-side platforms — an AAMP deployment in a production agency environment rather than a test workspace.

    Source: PR Newswire · last verified 2026-08-04

  • Yahoo DSP Agent Network

    Yahoo announced an Agent Network for its demand-side platform (DSP) in June 2026, an ecosystem of 23 partners connecting advertisers to AI-powered tools. Yahoo is also one of AdCP's six founding members, but the coverage of the Agent Network does not state which agentic protocol it uses, so protocol support should not be inferred from the membership.

    Source: MarTech Edition; Triton Digital · last verified 2026-08-04

  • WPP Buyer Agent for Video

    WPP launched its Buyer Agent for Video in June 2026, described as an AI-driven planning tool: it recommends video buys for human approval rather than executing them autonomously — an instance of the human-in-the-loop pattern that also appears in AAMP's SDK guardrails. The coverage does not state which protocol it uses.

    Source: MarTech Edition · last verified 2026-08-04

  • Omnicom agent-to-agent buys

    Omnicom runs live agent-to-agent buys for multiple clients, according to mid-2026 coverage of where agentic media buying actually stands. Neither the protocol used nor the volume transacted is specified in the available sources.

    Source: MediaPost; The Media Online · last verified 2026-08-04

  • Scope3

    Scope3 is one of AdCP's six founding members and committed engineering resources plus $10,000 per year at launch on October 15, 2025. It also built the buyer agent used in the first agent-to-agent media buy, which transacted LG Ads inventory against a Swivel seller agent for real money — making it the earliest documented AdCP buy-side implementation. No source describing the current shipped state of Scope3's commercial platform was located during verification.

    Source: Triton Digital; Samba TV; MediaPost · last verified 2026-08-04

  • Adform

    announced Adform publicly reaffirmed its commitment to open standards for agentic advertising on July 8, 2026, without naming a protocol, a product, or an implementation timeline.

    Source: ExchangeWire · last verified 2026-08-04

MCP servers from ad platforms

These servers expose a platform's own advertising API to agents over MCP. The sources describe them as MCP servers for those APIs and do not describe AdCP or AAMP support.

  • Microsoft Advertising MCP server

    Microsoft Advertising shipped an official MCP server on June 17, 2026. It is read-only: agents can read live campaign data, while changes to campaigns still require a human.

    Source: Digital Applied · last verified 2026-08-04

  • Pinterest ads MCP server

    Pinterest launched an MCP server for its ads API in the same period. The available coverage does not detail whether agents can write as well as read.

    Source: Digital Applied · last verified 2026-08-04

Gaps in this directory

The sell-side picture is no longer a single case: the Swivel, FreeWheel, DanAds/Sigma, and Prebid entries above are all documented, and RTL AdAlliance and theScore are named publishers. It is still much shorter than AgenticAdvertising.org's own count of 127+ member companies, and shorter than its agent registry, which listed 30 agents on August 20, 2026 — of which exactly one was a buying agent. Membership is not evidence of a live endpoint. The same caution applies on the AAMP side with one correction: PMG's Alli integration is production use, while Kochava's beta remains a sandbox rather than real spend. Trade press in July 2026 characterized adoption overall as "inevitable, but incremental," with governance running ahead of transaction volume.

Source: AgenticAdvertising.org and its registry API (the member and agent counts, verified 2026-08-20); PR Newswire (PMG); PPC Land; MediaPost · last verified 2026-08-04

Two claims were removed from this directory at the August 4, 2026 check because their citations did not support them. A HorizonOS Blu entry stated that Horizon Media runs buying agents in that platform, but neither cited article mentioned Horizon Media. At the August 18, 2026 check a primary source was located — Horizon Media's own June 18, 2026 release — so the entry is back above, rewritten to describe an agentic orchestration layer and to attribute it to neither protocol, which is as far as that release goes. A Yahoo DSP entry was rewritten onto the announcement that actually documents it. MediaPost's July 2026 survey also quotes a third party describing Fox Broadcasting as leading in agentic transactions, which is a characterization rather than a company announcement, so no Fox entry was added.
