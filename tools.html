Tools & platforms

A curated directory of tools, SDKs, and platforms in the agentic buying ecosystem — what they do and which protocols they speak.

Updated 4 August 2026 · all claims on this page verified on that date

Claims are badged by evidence strength; unbadged statements are verified as shipped.

How to read this directory

Entries are grouped by what a practitioner would reach for: the specifications and software development kits (SDKs) that implement a protocol, the buy-side platforms and agents that use them, and the Model Context Protocol (MCP) servers that ad platforms have published for their own APIs. Each entry says what the tool does and which protocol it speaks — AdCP (Ad Context Protocol), AAMP (Agentic Advertising Management Protocols), or MCP alone. Listing is not endorsement, and the directory covers only tools for which a dated public source was found.

Several sources cited below were verified through search-index summaries rather than direct fetches, because the publishers returned HTTP 403 to the research agent; each such claim was cross-checked against at least one further source.

Protocol implementations & SDKs

  • AdCP specification repository

    The AdCP specification and its reference material. The spec spans six protocol surfaces — Media Buy, Creative, Signals, Accounts, Governance, and Sponsored Intelligence — plus the Trusted Match Protocol for serve-time execution, with tasks carried over MCP or Google's Agent2Agent (A2A) transport. It is licensed Apache 2.0 with express patent grants, and the Prebid community maintains the reference sell-side implementation, kept separate from spec governance. The latest tagged release is v3.1.10 (August 4, 2026) on a weekly-plus cadence.

    Source: AdCP GitHub repository; AdCP GitHub releases; Adgentek glossary · last verified 2026-08-04

  • AAMP protocol repositories

    IAB Tech Lab publishes AAMP as a set of independently versioned open-source repositories: Agentic Direct (core communication and orchestration), Buyer Agent, Seller Agent, Registry Agent, the Agentic Real Time Framework, Agentic Audiences, iab-agentic-primitives (a shared contract library), and agentic-mobile. Commits were active through late July 2026 and licensing is mixed across repositories.

    Source: AAMP GitHub repository; IABTechLab agentic repositories · last verified 2026-08-04

  • AAMP Buyer & Seller Agent SDKs

    Transaction-ready SDKs that let a buyer agent and a seller agent negotiate, exchange rate cards, and execute programmatic deals with audit trails and human-approval guardrails. They are built on OpenDirect 2.1, incorporate AdCOM, and integrate with OpenRTB and Prebid; the same release added an Agentic Audiences OpenRTB extension, a Prebid module, and an open-source scorer. They shipped in AAMP 2.0. Sources conflict on that release date: IAB Tech Lab and LexisNexis coverage indicate April 2026, while one secondary source says June; April is the better-sourced date. reported

    Source: IAB Tech Lab; LexisNexis · last verified 2026-08-04

  • Agentic Real Time Framework (ARTF)

    AAMP's real-time bidding component, written in Rust and published under AGPL v3. It was released as ARTF v1.0 for public comment on November 13, 2025, with the comment period extended to January 15, 2026. announced IAB Tech Lab has claimed that a containerized, same-data-center architecture can cut bid request-response latency by up to roughly 80% (from 600–800 ms to about 100 ms); that figure is a vendor performance claim and has not been independently benchmarked.

    Source: IABTechLab agentic repositories; PR Newswire; MarTech · last verified 2026-08-04

  • FreeWheel Ad Context Protocol server

    A sell-side AdCP server that FreeWheel built for the agentic buys announced on January 6, 2026 with NBCUniversal, agency RPA, and Newton Research, in which buy-side agents negotiated with sell-side agents over MCP across premium video — including live NFL playoff linear inventory.

    Source: NBCUniversal · last verified 2026-08-04

Buy-side platforms & agents

Except where an entry says otherwise, the coverage documenting these deployments names the agent or platform without stating which protocol it uses, so protocol support should not be inferred from a company's membership in either standards body.

  • Kochava StationOne "IAB Workspace"

    An open-source workspace that integrates the AAMP Buyer Agent SDK, announced March 24, 2026 with an open beta in the first and second quarters of 2026. It lets buyers run standards-compliant agentic workflows against OpenDirect 2.1 without committing real spend — a sandbox rather than a live-spend environment.

    Source: GlobeNewswire; PPC Land · last verified 2026-08-04

  • Yahoo DSP

    Trade coverage of agentic media buying in mid-2026 lists agentic features in the Yahoo demand-side platform (DSP) among the deployments already running. Yahoo is also one of AdCP's six founding members; the coverage of the DSP's agentic features does not state which protocol they use.

    Source: MediaPost; MarTech Edition; Triton Digital · last verified 2026-08-04

  • HorizonOS Blu buying agents

    Horizon Media runs buying agents inside its HorizonOS Blu platform, cited in mid-2026 coverage among the live examples of agentic media buying. The available sources do not describe the platform's protocol support.

    Source: MediaPost; The Media Online · last verified 2026-08-04

  • WPP Buyer Agent for Video

    WPP's Buyer Agent for Video recommends video buys for human approval rather than executing them autonomously — an instance of the human-in-the-loop pattern that also appears in AAMP's SDK guardrails.

    Source: MarTech Edition; MediaPost · last verified 2026-08-04

  • Omnicom agent-to-agent buys

    Omnicom runs live agent-to-agent buys for multiple clients, according to mid-2026 coverage of where agentic media buying actually stands. Neither the protocol used nor the volume transacted is specified in the available sources.

    Source: MediaPost; The Media Online · last verified 2026-08-04

  • Scope3

    Scope3 is one of AdCP's six founding members and committed engineering resources plus $10,000 per year at launch on October 15, 2025. No source describing which agentic capabilities of Scope3's own platform have shipped was located during verification, so this entry records its protocol role only.

    Source: Triton Digital; Samba TV · last verified 2026-08-04

  • Adform

    announced Adform publicly reaffirmed its commitment to open standards for agentic advertising on July 8, 2026, without naming a protocol, a product, or an implementation timeline.

    Source: ExchangeWire · last verified 2026-08-04

MCP servers from ad platforms

These servers expose a platform's own advertising API to agents over MCP. The sources describe them as MCP servers for those APIs and do not describe AdCP or AAMP support.

  • Microsoft Advertising MCP server

    Microsoft Advertising shipped an official MCP server on June 17, 2026. It is read-only: agents can read live campaign data, while changes to campaigns still require a human.

    Source: Digital Applied · last verified 2026-08-04

  • Pinterest ads MCP server

    Pinterest launched an MCP server for its ads API in the same period. The available coverage does not detail whether agents can write as well as read.

    Source: Digital Applied · last verified 2026-08-04

Gaps in this directory

Beyond FreeWheel's server for the NBCUniversal buys, no publicly confirmed production AdCP sales endpoints were located. AgenticAdvertising.org's membership list runs to more than a hundred companies, but membership is not evidence of a live endpoint, and the same caution applies to AAMP: Kochava's beta is a sandbox, not real spend. Trade press in July 2026 characterized adoption overall as "inevitable, but incremental," with governance running ahead of transaction volume.

Source: Adgentek statistics; PPC Land; MediaPost · last verified 2026-08-04
