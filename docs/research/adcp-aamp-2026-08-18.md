## Summary

Nothing on the site was found to be wrong; one thing was found to be **out of date**, which is the
expected failure mode for a `high`-volatility claim. AdCP's release cadence moved past the version
the site named: **v3.1.15 (16 August 2026)** is now the latest tagged 3.1.x release, five patch
releases after the v3.1.10 the site carried, and a **v3.2.0-beta.0 pre-release (17 August 2026)**
opens a 3.2 line. The 3.2 changelog is substantive — taxonomy promotion, Trusted Match
publisher-authentication and context-targeting changes, cross-role governance enforcement, portable
and issuer-bound attestation schemas, and several deprecations — but it is a pre-release, so it is
badged `announced` and adds no eighth negotiation surface. The other two due claims still hold: the
v3.0.x maintenance line is alive (v3.0.24, 16 August), and AgenticAdvertising.org still publishes no
membership count, with the latest secondary figure (113+) sitting inside the 104+/117+ range the site
already reports.

Three new market developments were added: PubMatic's **agent-guardrail framework** in AgenticOS
(5 August), **InMobi's** conversational buying agent on Buyer Hub (13 August), and **AAMP component
releases past 2.3** — real release tags on the buyer-agent, seller-agent, and primitives repos that
**no IAB Tech Lab announcement calls "AAMP 2.4"**, so the version framing is badged `reported` while
the tags themselves are not.

Four open questions closed. The most useful is a **negative-turned-explanatory** result: AAMP 2.1 and
2.2 are not missing releases, they are component version tags under a milestone-numbering scheme, so
the site can now explain the hole in AAMP's announced version history instead of reporting it as
unexplained. A **primary source for HorizonOS Blu** was finally located, so the entry removed on
4 August returns — described as an agentic orchestration layer, attributed to neither protocol,
because that is as far as Horizon Media's release goes. One new question opened: **AAMP 2.3's own
dateline is disputed** between IAB Tech Lab's press-release index (27 July) and three other channels
(30 July).

## Open questions

### Closed this cycle

1. **AAMP 2.1 and 2.2 are undocumented** (carried since 2026-08-04) — closed with a different answer
   than expected. They were never press-released as protocol milestones, but they exist as component
   tags: `buyer-agent` v2.1.0 (20 July 2026), v2.1.1 (21 July), v2.2.0 (22 July); `seller-agent`
   v2.1.0/v2.1.1 and v2.2.0/v2.2.1/v2.2.2 on the same dates. The AAMP repository states that "each
   repository uses independent semantic versioning," so IAB Tech Lab's public milestone numbers are
   periodic labels over continuous component work. The announced version history still has a hole;
   the site can now explain it.
2. **HorizonOS Blu buying agents** (carried since 2026-08-04, entry removed from `tools.html`) —
   closed. Horizon Media's own PR Newswire release of 18 June 2026 exists, corroborated by MediaPost
   and Adweek the same day. Caveat preserved on the page: the release describes API/MCP-standard
   partner integration, not AdCP or AAMP.
3. **`agentic-direct` repository activity** — closed, confirmed stale (latest commit 27 January 2026),
   and now recorded on `aamp.html` as an observation without a conclusion about why.
4. **FreeWheel/AdCP attribution for the NBCUniversal buy** — closed negatively, more firmly. This
   cycle read FreeWheel's *own* release, which also names only "Model Context Protocol (MCP)" and
   never AdCP; the sole source claiming an "Ad Context Protocol server" is a secondary aggregator
   that contradicts FreeWheel's wording. The site's `reported` badge and citation stand as they are.

### Still open

5. **AAMP 2.0's release date (April vs. June 2026)** — unresolved as a primary-source fact; the IAB
   Tech Lab post remains undated on direct inspection. The evidence leans further toward April: a
   fourth secondary source (PPC Land, 30 July 2026) says 2.0 "launched in April," and the
   `seller-agent` v2.0 release carries an errata note that the tag "resolves to April 2026 commit
   predating announced features." Kept `reported` rather than resolved.
6. **AAMP 2.3's dateline** — newly open, and to be tracked the same way as the 2.0 dispute: IAB Tech
   Lab's press-release index says 27 July 2026, PR Newswire, MarTechCube, and PPC Land say 30 July.
   The site publishes 30 July and records the discrepancy.
7. **AgenticAdvertising.org's exact member count** — still unpublished. Re-checked this cycle only
   at the level of the secondary figure (113+, within the range already reported);
   `agenticadvertising.org/about` still states no number.
8. **The AAO's 501(c)(6) status** — still contested, unchanged. `CHARTER.md` in the spec repo says
   "a pending 501(c)(6) nonprofit trade association"; the organization's About page states it "is a
   Delaware 501(c)(6) nonprofit trade organization" while separately describing a formation phase
   with board elections pending. A registered EIN does not resolve tax-exempt determination, so this
   is if anything consistent with "pending." No IRS filing checked. Stays `reported`.
9. **Whether an "AAMP 2.4" exists as a protocol version** — the component tags are real, the
   milestone label is not sourced. Watch IAB Tech Lab's press releases and blog.
10. **Fox Broadcasting's agentic transactions** — not investigated this cycle. The only claim on
    record remains a third-party characterization in a MediaPost comment, correctly kept off the
    site.
11. **What the AdCP 3.2 line ships as stable, and when** — the pre-release changelog is not the same
    as a released spec, and the deprecations it lists (top-level media-buy lifecycle status,
    `publisher_domain` on `get_products`, inline provider credentials) will matter to implementers.
    High-volatility watch item.
