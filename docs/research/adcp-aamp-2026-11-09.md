# AdCP and AAMP refresh — 2026-11-09

Verified 2026-11-09. A volatility-sharded refresh with four verify shards and a discovery pass.
It was produced by the research-refresh workflow's apply stage from the shard verdicts and the
discovery notes. The apply stage did no web research of its own.

## Summary

Twenty-two claims were due this cycle.

- **Fourteen reached their cited source.** For four more (InMobi, WPP, Yahoo, Microsoft), only the
  cited secondary source was reachable, and it still supports the claim. Three had sources that
  returned HTTP 403 (Geopath/Ipsos, the VIOOH rollout and AdQuick). One, the AdCP roadmap note,
  was not re-checked.
- **Nothing on the site was found to be wrong.** Four claims moved because the facts moved, and
  all four moved in the direction the site already described.
- **One wording correction.** Microsoft's pilot has nine partners, of which the source names six.
  The site had said "nine named".
- **No badge state changed.**

Release lines and counts:

- **AdCP's stable line is v3.2.9** (9 November 2026), whose release notes read only "AdCP 3.2.9".
  The 3.1 line is at **v3.1.32** (5 November) and the 3.3 pre-release line at **v3.3.0-beta.5**
  (7 November). The 3.0 line has not tagged since v3.0.28 (7 October).
- **The 3.3 changelog is now partly readable.** It adds `request_account`, measurement provenance,
  seller offers, live creative updates and match-key schemas, each marked experimental. It also
  graduates `sales-fixed-rate` from preview to stable. The sections read, from beta.5 back to
  partway through beta.1, contain no out-of-home item.
- **Membership is 159+ on both homepages**, up from 157+.
- **The agent registry rose to 35** (28 sales, 4 signals), reversing two consecutive declines.
- **AAMP's component repositories still have no tag after 18 August.** That is about twelve weeks.
  The OpenProposal repository still shows the 22 October comment close, while PPC Land reports
  the extension to 10 November, which is the day after this run.

The 3.2.1 changelog's out-of-home items were all re-confirmed in one read. That covers the
`ooh_metrics` block, the OpenOOH identifiers and the experimental static contract, which the
2026-11-01 run could not reach. No SDAW norm-level claim was touched. The local norm folder was not
reachable, as expected for a cloud run.
