## Summary

**AdCP 3.2 is stable.** v3.2.1 was published on 1 October 2026 and is marked Latest on the
releases page, ending a pre-release line that opened on 17 August with v3.2.0-beta.0 and ran
through v3.2.0-rc.7 on 27 September. There is no 3.2.0: the 3.2.1 changelog section states that
3.2.0 "is a permanently withdrawn version number and was never released", accidentally cut on
30 June 2026 from 3.1-era main, so 3.2 general availability ships as 3.2.1 with the wire-protocol
pin staying at "3.2". This closes the open question the 2026-09-15 note led with — whether the line
was converging at all. It was, five release candidates after the note asked. The v3.1.x line took
one more tag, v3.1.24 on 23 September, and continues as a maintenance line; v3.0.x still stands at
v3.0.26.

Because two verifiers flagged the 3.2 release state, the apply stage re-read the releases page and
the 3.2.1 changelog section directly on the run date before editing any page. That check confirmed
v3.2.1 as Latest and found the out-of-home schema work inside the stable release:
`dooh_placement_attributes`, the `sales-dooh` specialism, DOOH share of voice as a
duration-weighted time share and versioned OpenOOH identifiers, plus the static out-of-home channel
contract (`ooh_metrics`), which the changelog marks "experimental in 3.2". The verifier had
suggested `announced` for the out-of-home schema row on the grounds that the release dates it
fetched looked unreliable; the direct read settles it, and the row is `shipped`, with the
experimental marker stated on the page.

**AAMP 3.0 has been announced, not shipped.** IAB Tech Lab announced it on 22 September 2026; its
new part, OpenProposal, is a draft open for comment until 22 October 2026, with 71 fields, only three
needing a counterparty round trip, and line items routed to OpenDirect 2.1, the Deals API or
OpenRTB 2.6. The legal note recorded it first; this refresh carries it onto the AAMP, comparison and
release pages and the home-page changelog. AAMP's component repositories have still not tagged since
18 August — six weeks — and Agentic Direct's last commit is still 27 January 2026.

The counts moved in opposite directions. The organization's own membership figure rose from 142+ to
**148+** on both homepages. The agent registry fell from 35 to **34** — 28 sales, 3 signals,
1 creative, 1 buying, 1 uncategorized — the first decline this site has recorded, and the
buying-agent count is still exactly one.

Most of the remaining movement is **evidence grading, not news**. Re-reading sources against the
site's badge rules moved six tool and deployment claims off unbadged prose:

- WPP's Buyer Agent for Video, Yahoo's DSP Agent Network and Microsoft Advertising's MCP server rest
  on secondary coverage only, so they are now `reported`. Microsoft's server is an open pilot with
  nine named partners, not generally available.
- Pinterest's ads MCP server is read-only and in alpha with named partners, so it is `announced`, and
  the site's statement that coverage did not say whether agents can write is replaced by what the
  coverage does say.
- PubMatic's Clubtails release and InMobi's Business Wire release both returned HTTP 403; with only
  secondary coverage reachable, both are `reported` and keep their 2026-09-02 dates.

Five factual corrections, none a reversal:

- **The first agent-to-agent buy** is no longer described as a real transaction "with money changing
  hands". MediaPost describes it as a demonstration in which the buyer acted for a fictional brand,
  Ematini. The claim was already `reported`; the wording now matches the source.
- **DOOH in AdCP 3.0** was not "the first stable release to name the medium" — the what's-new page
  says `dooh` carried over unchanged from v2.
- **DOOH bid latency.** The 100–300 ms figure the OOH page gave is not in its source, which gives
  100–200 ms as the standard window for web real-time bidding and says DOOH requests are often
  prefetched minutes or hours before playout.
- **Displayce's three MCP agents** are campaign planning from a brief, sales-presentation
  preparation and performance analysis. Neither source describes a campaign-activation agent.
- **Kochava StationOne's** "Q1–Q2 2026" beta window appears in neither source and is dropped.

One source came back: martech.org, blocked for three consecutive cycles, was reachable and states
the ARTF ~80% latency figure as the site gives it. The claim stays `reported` as an unbenchmarked
vendor claim but now carries a 2026-10-01 date. lbbonline.com and adquick.com still returned 403;
the VIOOH Seller Agent row, whose primary report is on lbbonline, therefore moves to `reported`. The
VIOOH self-serve rollout was planned for Q3 2026; that quarter ended on 30 September with no
completion announcement located.

No claim acquired a verification date this run did not earn: the five rows whose sources were not
reached kept their prior dates.
