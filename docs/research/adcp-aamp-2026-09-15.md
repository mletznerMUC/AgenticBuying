## Summary

Nothing on this site turned out to be wrong this cycle. Nine of the eleven due
claims reached their sources; five of those nine had moved, and every one of the
five moved in the direction the site already described. The corrections are version
numbers and counts, not reversals.

The substantive finding is about **AdCP's release cadence, which has accelerated on
both lines at once**. The stable 3.1 line took three tags in eight days — v3.1.21
on 9 September, v3.1.22 on 13 September, v3.1.23 on 14 September — against the
weekly-plus cadence the site describes. The 3.2 pre-release line took three more
release candidates in the same window, rc.1 on 5 September through rc.3 on
14 September, and rc.3 is the sixteenth pre-release since 17 August with still no
stable 3.2 release. Each candidate continues to add surface rather than only fix:
rc.1 deprecates cross-buy delivery aggregates and adds a Reliable Reporting
capability with vendor measurement disclosure, rc.2 adds buyer and orchestrator
storyboards, restored viewability constraints and cursor pagination, and rc.3 adds
media-buy frequency capping and request-only targeting schemas. Four release
candidates in ten days, none of them purely stabilizing, is evidence that the line
is still widening rather than converging — which is why the whole 3.2 line stays
`announced`.

One incidental observation worth keeping: the documentation site's what's-new page
for 3.1 still links its normative specification at the **3.1.21 distribution path**,
one release behind the latest tag. The docs and the tags are drifting apart at this
cadence, which matters for a reader who takes the documentation as the spec.

The two counts both grew. The organization's own membership figure moved from 132+
to 142+ on both homepages, and the agent registry moved from 32 to 35 agents. The
registry's composition is the more interesting half: the three added are two sales
agents and one that the API returns **uncategorized** — a type the site had not
previously had to describe. The buying-agent count is still exactly one, unchanged
since the 31 July snapshot, so the sell-side skew the site has reported for three
cycles is not merely holding but widening.

Against that, **AAMP's component repositories have gone quiet.** All three — seller-agent,
buyer-agent, iab-agentic-primitives — still stand where they stood on 18 August, a
four-week pause following a fortnight of weekly tags, and no IAB Tech Lab
announcement naming an "AAMP 2.4" has appeared. The claim re-verified unchanged, but
the silence is now long enough to be a fact about the project rather than a gap in
the check. The two protocols' cadences are diverging.

Two claims did not reach their sources, and neither acquired a verification date
this run did not earn:

- **The ARTF latency figure.** martech.org returned HTTP 403 again, retried twice,
  with a Wayback attempt blocked by the tool. That is three consecutive cycles
  blocked. It keeps its 2026-08-04 date and its `reported` badge. The claim's own
  framing — a vendor figure, not independently benchmarked — still fits what can be
  said about it, but a source blocked across three cycles is no longer a transient
  failure, and the question of whether to carry the figure at all is now live.
- **VIOOH's Q3 2026 self-serve rollout and protocol registrations.** lbbonline.com
  returned HTTP 403 on repeated attempts and no archive copy was recoverable. This
  one is a genuine loss: the claim was `announced` on the strength of that single
  article, and with the article unreachable there is no longer a retrievable source
  for the plan itself, never mind its completion. It moves to `reported` on
  `ooh.html` and keeps its 2026-09-04 date. The caveat was kept rather than deleted,
  since the plan being unverifiable is itself what a reader needs to know.

The two claims verified against unchanged sources — AdCP's `specs/static-ooh.md`
draft and the 3.2 out-of-home schema work — both held exactly as written. The draft
is still headed "Status: Draft — for discussion with AdQuick and the Media Buy
working group" and still carries the `ooh` property type, `panel_id`,
`{authority}:{id}` measurement references, the posting-evidence array and
illuminated hours. Seven days on, it has not advanced toward a released schema.

## Open questions

### Closed this cycle

None. This cycle was a verification pass over high-volatility claims, not a
discovery pass, and no open question in [`README.md`](README.md) was within its
scope.

### Newly open

- **Whether AdCP 3.2 is converging at all.** This replaces the narrower "does 3.2
  have an intended stable date?" The line has now run sixteen pre-releases over
  twenty-eight days, and its four release candidates each added capability rather
  than only fixing: Reliable Reporting and a deprecation in rc.1, storyboards and
  cursor pagination in rc.2, frequency capping and new targeting schemas in rc.3.
  A release candidate that keeps taking minor changes is not behaving as a release
  candidate, and the site should not describe the line as nearly stable on the
  strength of the "rc" label alone.
- **Whether the AdCP documentation site tracks the tags at all.** Its 3.1
  what's-new page links the spec at the 3.1.21 path while the latest tag is
  v3.1.23. One release of lag could be publishing latency; at three tags in eight
  days it is worth knowing whether the docs are generated from tags or updated by
  hand, because the site cites both as sources for the same facts.
- **What the registry's "uncategorized" agent type means.** The API returned one
  agent with no type among 35. Whether that is a data-entry gap, a new category
  being introduced, or an agent that fits none of sales/creative/signals/buying is
  not answerable from the API response alone.
- **Whether AAMP's component work has stopped or merely paused.** Four weeks with
  no tag on any of the three repositories, after a fortnight of weekly releases and
  with the Agentic Direct commit gap now approaching eight months. The site records
  the pause as a fact; what it means is not sourced.

### Carried forward, unchanged

The open questions from the 2026-09-02, 2026-09-04, 2026-09-08 and 2026-09-09 notes
all stand, none having been in scope this cycle. Two are affected by what this run
found, and are restated here in their sharpened form:

- **The ARTF latency figure now rests on a source blocked for three consecutive
  cycles.** Previously framed as "if the block persists." It has persisted. The
  choice is now between finding a different source for the ~80% figure and removing
  it from the pages that carry it; keeping it indefinitely on a permanently
  unreachable citation is the one option the site's own sourcing rules do not
  support.
- **VIOOH's Q3 2026 rollout is no longer merely unconfirmed — it is unverifiable.**
  The question was whether the plan had been completed; it is now also whether the
  plan can be re-read at all. The quarter ends in two weeks, so a completion
  announcement, if one comes, would resolve both halves at once.
