How to read these tables

AdCP (Ad Context Protocol) and AAMP (Agentic Advertising Management Protocols) do not version comparably, so their releases are tracked in separate tables and the numbers should never be read across them.

AdCP tags the specification itself. Releases land on GitHub at a weekly-plus cadence, and three lines are active at once: 3.1 as the current stable line, 3.0 still receiving maintenance releases, and 3.2 in pre-release.

AAMP announces framework milestones and versions its component repositories separately. Component tags run ahead of the announced milestones — buyer-agent and seller-agent passed through v2.1.x and v2.2.x between the 2.0 and 2.3 announcements, and stand at v2.4.2 while the last announced milestone is 2.3. A component version is therefore not a protocol version.

A higher number says nothing about maturity or scope. Each table below states what one release means for that project, and lists stable releases before pre-releases. For the surrounding history — launches, deployments, and governance — see the timelines on AdCP and AAMP.
