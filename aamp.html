AAMP — Agentic Advertising Management Protocols

A deep dive into IAB Tech Lab's AAMP framework: scope, governance, specification state, and ecosystem support.

What it is

AAMP — Agentic Advertising Management Protocols — is the IAB Tech Lab's open-source umbrella framework for all of its agentic advertising work. Rather than defining a new task language from scratch, AAMP extends the Tech Lab's existing standards — OpenRTB, OpenDirect 2.1, AdCOM, and VAST — with agentic layers, and uses Anthropic's Model Context Protocol (MCP) and Google's Agent2Agent (A2A) as agent interfaces.

Source: IAB Tech Lab AAMP standards page; AAMP GitHub repository; dev.to analysis · last verified 2026-09-02

The IAB Tech Lab formally named the initiative AAMP on February 26, 2026 (announced by CEO Anthony Katsur at Beet Retreat), explicitly to end market confusion; before that, the work had shipped under separate names such as the Agentic RTB Framework (ARTF) and the User Context Protocol. A naming note: IAB Tech Lab's standards page and press releases use the plural "Agentic Advertising Management Protocols," while one official IAB video title uses the singular "Agentic Ad Management Protocol."

Source: PPC Land; IAB video · last verified 2026-09-02

Governance

AAMP is developed by IAB Tech Lab's Agentic Task Force together with member companies and working groups. The standards page presents the framework as three pillars: Agentic Foundations, Agentic Protocols, and Trust and Transparency.

Source: IAB Tech Lab AAMP standards page · last verified 2026-09-02

The Trust and Transparency pillar's Agent Registry is live rather than an ambition: IAB Tech Lab states that it "is open to members, and non-members, and is free for anyone to sign up and register," and describes it as providing neutral agent transparency and accountability across the ecosystem. The registry's public code repository, by contrast, is published as an example implementation and carries no license.

Source: IAB Tech Lab AAMP standards page; AAMP GitHub repository · last verified 2026-09-02

Capabilities

AAMP's public code lives across multiple repositories in the IABTechLab GitHub organization, each versioned independently: Agentic Direct (core communication and orchestration), Buyer Agent, Seller Agent, Registry Agent, the Agentic Real Time Framework (ARTF, written in Rust, AGPL v3), Agentic Audiences, iab-agentic-primitives (a shared contract library), and agentic-mobile. Commit activity ran through August 4, 2026, with the Buyer Agent pushed that day and the Seller Agent on July 30. Licensing is genuinely mixed: most components are Apache 2.0, ARTF is AGPL v3, Agentic Audiences carries a non-standard license declaration, and the registry example repository carries none.

Source: AAMP GitHub repository; IABTechLab agentic repositories · the repository list and licensing last verified 2026-09-02; the commit-activity dates last verified 2026-08-04

Those repositories kept releasing after AAMP 2.3: the Seller Agent tagged v2.4.0 and v2.4.1 on August 4 and 5, 2026, the Buyer Agent and iab-agentic-primitives tagged v2.4.1 and v0.5.1 on August 10, and both agents tagged v2.4.2 on August 18. reported No IAB Tech Lab press release or blog post names an "AAMP 2.4," so the tags document component work rather than an announced protocol version. None of those tags moved between August 18 and September 2, 2026. Agentic Direct is the exception to the activity: its most recent commit is dated January 27, 2026, so the gap between it and the other components has widened rather than closed. No source explains why.

Source: IABTechLab seller-agent releases; buyer-agent releases; iab-agentic-primitives releases; agentic-direct commit history · last verified 2026-09-02

The standards page also names framework components that are not separate repositories: an Agentic Ad Object derived from AdCOM and an Agentic Deals API. It describes Agentic Audiences as "formerly the LiveRamp UCP donation." reported The January 2026 press release that this site's timeline associates with a User Context Protocol rebrand does not mention UCP or Agentic Audiences at all, so the rebrand is attested only by the standards page's retrospective phrasing and no source dates it.

Source: IAB Tech Lab AAMP standards page; IAB Tech Lab — Agentic Roadmap · last verified 2026-09-02

AAMP 2.0 delivered transaction-ready Buyer Agent and Seller Agent SDKs (software development kits) that can negotiate, share rate cards, and execute programmatic deals with audit trails and human-approval guardrails. The SDKs are built on OpenDirect 2.1, incorporate AdCOM, and integrate with OpenRTB and Prebid; the release also included an Agentic Audiences OpenRTB extension, a Prebid module, and an open-source scorer. Sources conflict on the release date: three secondary sources put it in April 2026 — LexisNexis, an IAB New Zealand post dated April 29 describing the SDKs as downloadable working software, and the standards page's own April 23 revision date — while one secondary analysis says 2.0 landed in June. April is the better-sourced date, but IAB Tech Lab's own release post carries no visible dateline, so no primary date could be read. reported Two further data points are consistent with April and neither is a dateline on the release itself: PPC Land's July 30 report states that 2.0 launched in April, and the Seller Agent repository's v2.0 release note carries an erratum dated July 22, 2026 warning that the tag resolves to an April 2026 commit predating the announced features. A re-check on September 2, 2026 found no new evidence either way, so the date remains disputed.

Source: IAB Tech Lab; LexisNexis; IAB New Zealand; PPC Land; the seller-agent release notes · last verified 2026-09-02

AAMP 2.3, released July 30, 2026, targets enterprise-ready deployment: pricing guardrails so agents cannot invent prices, with server-side trust verification described as covering "every price-moving path"; a vendor-approval gate in the Buyer Agent tied to the IAB Diligence Platform and SafeGuard Privacy; deterministic spend commitments that require human approval outside set value thresholds; Agentic Audiences v1.0 declared ready for transactions; and broader platform support — Amazon Bedrock AgentCore, Databricks, buying on Meta, and Google Ad Manager reporting. The release credits open-source contributions from HyperMindz (a Deals Sync API MCP server) and Mixpeek (a content taxonomy parser for IAB Content Taxonomy v3), alongside SafeGuard Privacy and Adform. The July 30 date is now consistent across every channel checked: IAB Tech Lab's press-release index, its RSS feed — which gives a machine-readable publication time of July 30, 2026 for the companion post — PR Newswire, and PPC Land. reported This site previously recorded a discrepancy, IAB Tech Lab's own index dating 2.3 to July 27. That reading is no longer observable on the index and no source states July 27, so the discrepancy is treated as resolved rather than live; the earlier record is kept here because it is this site's own prior observation and nothing explains the change.

Source: PR Newswire; PPC Land; MediaPost; IAB Tech Lab's press-release index; IAB Tech Lab RSS feed · last verified 2026-09-02

reported Two elements of that release read differently in the code than in the announcement. The agentic-audiences repository carries no tagged release, its README still describes the repository as LiveRamp's initial proposal, and the embedding-exchange specification inside the directory named specs/v1.0 is headed "Draft v0.1" and marked "Status: Draft" — which is hard to square with "Agentic Audiences v1.0 ready for transactions."

The release's two announced deployment platforms are documented in different places, and the difference is structural rather than a gap in the record. The Amazon Bedrock AgentCore path is documented inside the Seller Agent repository, with an entrypoint, runtime patches, and a deployment flow — AAMP's own code knows about it. Databricks appears nowhere in the AAMP codebase: a code search across the whole IABTechLab organization finds Databricks named only in unrelated UID2 documentation, and Lakebase not at all. The Databricks path lives on Databricks' side instead, published the same day as AAMP 2.3: a reference implementation and self-deploy accelerator that runs buyer, seller, and registry agents with Lakebase — Databricks' serverless Postgres — as the agents' transactional store and CrewAI as the agent framework, built on IAB Tech Lab's open-source Seller Agent SDK. That is what AAMP 2.3's pluggable-storage framing allows, so the absence from the AAMP repositories is expected rather than surprising. reported Neither IAB Tech Lab nor Databricks states that this accelerator is the integration the release credits, and neither describes a partnership: the identification rests on the shared SDK and the coincident date, and IAB Tech Lab's own announcement names no repository for either platform. The accelerator is also published under the Databricks License rather than the Apache-2.0 of the SDK it builds on.

Source: IABTechLab agentic-audiences and its embedding-exchange specification; seller-agent Bedrock AgentCore documentation; databricks-iab-aamp-buy-sell; Databricks — agentic media buying on Databricks, 30 July 2026 · last verified 2026-09-02

reported For ARTF, IAB Tech Lab has claimed that a containerized, same-data-center architecture can cut bid request-response latency by up to roughly 80% (from 600–800 ms to about 100 ms). This is a vendor performance claim and has not been independently benchmarked. It is also the one claim on this page that could not be re-checked on September 2, 2026: the sole source carrying the figure returned HTTP 403 to repeated fetches, so the statement stands on its August 4, 2026 reading.

Source: MarTech · last verified 2026-08-04; unreachable on 2026-09-02

Version-numbering note: the announced milestones jump from 2.0 to 2.3, and the reason is how AAMP is versioned rather than a missing release. The AAMP repository states that each component repository uses independent semantic versioning, and the Buyer and Seller Agent repositories do carry v2.1.x and v2.2.x tags dated July 20–22, 2026. IAB Tech Lab's public milestone numbers sit above that continuous component work, and no press release or blog post announces an AAMP 2.1 or 2.2 as a protocol release — so the announced version history has a gap that the repository history does not, and a milestone number cannot be read as the version of any single component.

Source: AAMP GitHub repository; IABTechLab buyer-agent releases; seller-agent releases · last verified 2026-09-02

Adoption & ecosystem

PMG integrated AAMP's Buyer Agent architecture, Sub-Agent architecture, and Agent Registry into Alli, its own operating system, announced April 7, 2026. IAB Tech Lab describes Alli as being used across the agency to manage media buying, integrate data providers, and coordinate with demand-side platforms, which makes this the AAMP deployment on this page that runs in a production agency environment rather than a test workspace.

Source: PR Newswire · last verified 2026-09-02

Kochava integrated the AAMP Buyer Agent SDK into its StationOne platform as an open-source "IAB Workspace," announced March 24, 2026, with an open/public beta in Q1–Q2 2026. It lets buyers test standards-compliant agentic workflows on OpenDirect 2.1 without committing real spend.

Source: GlobeNewswire; PPC Land · last verified 2026-09-02

On the platform side, AAMP 2.3 added support for Amazon Bedrock AgentCore and Databricks, buying on Meta, and Google Ad Manager reporting. In the broader market, trade press in July 2026 characterized agentic media buying adoption overall as "inevitable, but incremental," with industry emphasis on governance over speed.

Source: PR Newswire; MediaPost · last verified 2026-09-02
