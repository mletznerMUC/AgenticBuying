AAMP — Agentic Advertising Management Protocols

A deep dive into IAB Tech Lab's AAMP framework: scope, governance, specification state, and ecosystem support.

What it is

AAMP — Agentic Advertising Management Protocols — is the IAB Tech Lab's open-source umbrella framework for all of its agentic advertising work. Rather than defining a new task language from scratch, AAMP extends the Tech Lab's existing standards — OpenRTB, OpenDirect 2.1, AdCOM, and VAST — with agentic layers, and uses Anthropic's Model Context Protocol (MCP) and Google's Agent2Agent (A2A) as agent interfaces.

Source: IAB Tech Lab AAMP standards page; AAMP GitHub repository; dev.to analysis · last verified 2026-08-04

The IAB Tech Lab formally named the initiative AAMP on February 26, 2026 (announced by CEO Anthony Katsur at Beet Retreat), explicitly to end market confusion; before that, the work had shipped under separate names such as the Agentic RTB Framework (ARTF) and the User Context Protocol. A naming note: IAB Tech Lab's standards page and press releases use the plural "Agentic Advertising Management Protocols," while one official IAB video title uses the singular "Agentic Ad Management Protocol."

Source: PPC Land; IAB video · last verified 2026-08-04

Governance

AAMP is developed by IAB Tech Lab's Agentic Task Force together with member companies and working groups. The framework is presented as three complementary pillars: execution infrastructure, shared standards, and neutral agent transparency. Whether the transparency pillar's registry service has actually shipped, as opposed to remaining a pillar-level ambition, could not be verified from accessible sources. reported

Source: IAB Tech Lab; IAB Canada · last verified 2026-08-04

Capabilities

AAMP's public code lives across multiple repositories in the IABTechLab GitHub organization, each versioned independently: Agentic Direct (core communication and orchestration), Buyer Agent, Seller Agent, Registry Agent, the Agentic Real Time Framework (ARTF, written in Rust, AGPL v3), Agentic Audiences, iab-agentic-primitives (a shared contract library), and agentic-mobile. Commit activity continued through late July 2026.

Source: AAMP GitHub repository; IABTechLab agentic repositories · last verified 2026-08-04

AAMP 2.0 delivered transaction-ready Buyer Agent and Seller Agent SDKs (software development kits) that can negotiate, share rate cards, and execute programmatic deals with audit trails and human-approval guardrails. The SDKs are built on OpenDirect 2.1, incorporate AdCOM, and integrate with OpenRTB and Prebid; the release also included an Agentic Audiences OpenRTB extension, a Prebid module, and an open-source scorer. Sources conflict on the release date: IAB Tech Lab and LexisNexis coverage indicate April 2026 (announcements around April 23–24), while one secondary source says 2.0 landed in June; April is the better-sourced date. reported

Source: IAB Tech Lab; LexisNexis · last verified 2026-08-04

AAMP 2.3, released July 30, 2026, targets enterprise-ready deployment: a pricing-provenance field so agents cannot invent prices, a vendor-approval gate in the Buyer Agent tied to the IAB Diligence Platform and SafeGuard Privacy, OpenRTB-based audience embeddings with a Prebid module, compatibility with Amazon Bedrock and Databricks, and finalization of key standards.

Source: PR Newswire; PPC Land; MediaPost · last verified 2026-08-04

announced For ARTF, IAB Tech Lab has claimed that a containerized, same-data-center architecture can cut bid request-response latency by up to roughly 80% (from 600–800 ms to about 100 ms). This is a vendor performance claim and has not been independently benchmarked.

Source: MarTech · last verified 2026-08-04

Gap note: the contents and dates of AAMP 2.1 and 2.2 are not documented in accessible sources; only 2.0 and 2.3 are.

Adoption & ecosystem

Kochava integrated the AAMP Buyer Agent SDK into its StationOne platform as an open-source "IAB Workspace," announced March 24, 2026, with an open/public beta in Q1–Q2 2026. It lets buyers test standards-compliant agentic workflows on OpenDirect 2.1 without committing real spend.

Source: GlobeNewswire; PPC Land · last verified 2026-08-04

On the platform side, AAMP 2.3 added compatibility with Amazon Bedrock and Databricks. In the broader market, trade press in July 2026 characterized agentic media buying adoption overall as "inevitable, but incremental," with industry emphasis on governance over speed.

Source: PR Newswire; MediaPost · last verified 2026-08-04
