AdCP — Ad Context Protocol

A deep dive into the Ad Context Protocol: what it standardizes, who governs it, and which capabilities are real today.

What it is

AdCP (Ad Context Protocol) is an open standard that lets AI agents manage advertising operations: inventory discovery, media buying, creative management, audience and signal activation, and serve-time decisioning. The specification defines two layers — planning-time negotiation between buyer and seller agents, and impression-time decisioning.

Source: AdCP GitHub repository · last verified 2026-08-04

AdCP launched on October 15, 2025 with six founding members — Yahoo, PubMatic, Scope3, Optable, Swivel, and Triton Digital — each committing engineering resources plus $10,000 per year. The initial public release was labeled v2.0.0 and included Media Buy, Curation, and Audience Activation (Signals) protocols, built on Anthropic's Model Context Protocol (MCP).

Source: PPC Land, corroborated by Triton Digital and Samba TV · last verified 2026-08-04

The protocol positions itself as "parallel to OpenRTB, not a replacement": rather than extending real-time bidding, it defines a purpose-built task language (discover products, create media buy, generate creative, activate audience) carried over MCP or Google's Agent2Agent (A2A) transports.

Source: dev.to analysis; Star Global · last verified 2026-08-04

Governance and licensing

AdCP is governed by AgenticAdvertising.org (also called the Agentic Advertising Organization, "AAO"), a Delaware-incorporated nonprofit trade association whose 501(c)(6) status is pending. It has four equally weighted voting classes — brands, agencies, publishers, and technology providers — and deliberately separates spec governance from implementation: the Prebid community maintains the reference sell-side implementation. The spec repository is licensed under Apache 2.0 with express patent grants, and contributors are bound by an IPR policy.

Source: AdCP GitHub repository; Adgentek glossary · last verified 2026-08-04

Capabilities

The current specification spans six protocol surfaces — Media Buy, Creative, Signals, Accounts, Governance, and Sponsored Intelligence — plus the Trusted Match Protocol for serve-time execution across web, mobile, connected TV (CTV), AI assistants, and retail.

Source: AdCP GitHub repository · last verified 2026-08-04

Secondary sources report that AdCP reached general availability on its 3.0 spec line in 2026. Note: the "GA" claim appears in secondary sources only; no primary announcement from AgenticAdvertising.org has been located, so the GA label should be read with that caveat. reported On GitHub, the spec is on an active v3.1.x line: the latest tagged release as of this writing is v3.1.10 (August 4), with a weekly-plus release cadence through July and August (v3.1.3 was withdrawn for a semver violation).

Source: Adgentek glossary; The Current; AdCP GitHub releases · last verified 2026-08-04

announced Roadmap items — not yet shipped — include curation, creative generation, and performance attribution.

Adoption & ecosystem

AgenticAdvertising.org's membership is reported at between 104+ and 117+ member companies, with the figures differing by report date; the exact current count is unverified because no dated primary membership page has been confirmed. reported Members named across sources include Yahoo, PubMatic, Scope3, Samba TV, The Weather Company, Magnite, MiQ, LG Ad Solutions, Butler/Till, Raptive, and Affinity.

Source: Adgentek statistics; Samba TV; PPC Land · last verified 2026-08-04

The first cross-platform agentic media buys were announced on January 6, 2026 by NBCUniversal, agency RPA, FreeWheel, and Newton Research: buy-side agents negotiated with sell-side agents over MCP, including live NFL playoff linear inventory for a brand's Q1 2026 investment. FreeWheel built an Ad Context Protocol server for the effort. Beyond that case, publicly confirmed production AdCP sales endpoints remain limited — membership is broader than verified live deployment.

Source: NBCUniversal; Adgentek statistics · last verified 2026-08-04
