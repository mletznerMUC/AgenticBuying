AdCP — Ad Context Protocol

A deep dive into the Ad Context Protocol: what it standardizes, who governs it, and which capabilities are real today.

Updated 18 August 2026 · the 18 August refresh re-checked the release lines and the membership figures; every other claim carries the date it was last verified in its own source line

Primary source: adcontextprotocol.org

Claims are badged by evidence strength; unbadged statements are verified as shipped.

What it is

AdCP (Ad Context Protocol) is an open standard that lets AI agents manage advertising operations: inventory discovery, media buying, creative management, audience and signal activation, and serve-time decisioning. The specification defines two layers — planning-time negotiation between buyer and seller agents, and impression-time decisioning.

Source: AdCP GitHub repository · last verified 2026-08-04

AdCP launched on October 15, 2025 with six founding members — Yahoo, PubMatic, Scope3, Optable, Swivel, and Triton Digital — each committing engineering resources plus $10,000 per year. The initial public release was labeled v2.0.0 and included Media Buy, Curation, and Audience Activation (Signals) protocols, built on Anthropic's Model Context Protocol (MCP).

Source: PPC Land, corroborated by Triton Digital and Samba TV · last verified 2026-08-04

The protocol positions itself as "parallel to OpenRTB, not a replacement": rather than extending real-time bidding, it defines a purpose-built task language (discover products, create media buy, generate creative, activate audience) carried over MCP or Google's Agent2Agent (A2A) transports.

Source: dev.to analysis; Star Global · last verified 2026-08-04

Governance and licensing

AdCP is governed by AgenticAdvertising.org (also called the Agentic Advertising Organization, "AAO"), a Delaware-incorporated nonprofit trade association. It has four equally weighted voting classes — brands, agencies, publishers, and technology providers — and deliberately separates spec governance from implementation: the Prebid community maintains the reference sell-side implementation. The spec repository is licensed under Apache 2.0 with express patent grants, and contributors are bound by an IPR policy. reported Its tax status is described inconsistently by its own sources: the specification repository calls it "a pending 501(c)(6) nonprofit trade association," while the organization's About page states that it is a Delaware 501(c)(6) nonprofit and lists an employer identification number, and also describes the organization as being in a "formation phase."

Source: AdCP GitHub repository; AgenticAdvertising.org — About · last verified 2026-08-04

The organization's bylaws provide for a 40-director elected board drawn from those same four member categories; the interim advisors it names are Randall Rothenberg, former CEO of the Interactive Advertising Bureau, and Matthew Egol, formerly of Booz & Company. Membership is paid and tiered, from an Explorer tier at $50 per year to a Leader tier at $50,000 per year, with voting rights attached to contributor seats rather than to the lowest tier.

Source: AgenticAdvertising.org — About; AgenticAdvertising.org — Membership · last verified 2026-08-04

Capabilities

The current specification spans seven negotiation-layer surfaces — Media Buy, Creative, Signals, Accounts, Governance, Brand, and Sponsored Intelligence — plus the Trusted Match Protocol, which covers Context Match and Identity Match, for serve-time execution across web, mobile, connected TV (CTV), AI assistants, and retail. The documentation marks Sponsored Intelligence, which covers brand sessions inside AI assistants, as experimental.

Source: AdCP GitHub repository; AdCP documentation · last verified 2026-08-04

The 3.0 line reached general availability: the specification documentation states that "v2 is unsupported as of 3.0 GA and fully deprecated on August 1, 2026 (UTC)." No GA date for 3.0 itself is published, so the milestone is documented while its date is not. Version 3.0 widened the protocol to brand identity and rights (a brand.json standard and a community brand registry), creative workflow upgrades, governance, collections and installments, and 20 media channels including broadcast television — up from nine channels in v2.

Source: AdCP documentation — what's new in 3.0 · last verified 2026-08-04

Version 3.1 is the current stable minor version, and every 3.1 change is additive over 3.0: new fields are optional and no required field was removed, so a 3.0-conformant client keeps working. On GitHub the spec is on an active v3.1.x line — the latest tagged release is v3.1.15, published August 16, 2026, at a weekly-plus cadence that produced five patch releases in the twelve days after v3.1.10 — while a parallel v3.0.x maintenance line still receives releases (v3.0.22 on July 24, the same day as v3.1.5; v3.0.24 on August 16). Release v3.1.3 was withdrawn: the project states it "added a stable protocol schema field in a patch release, violating the 3.1.x release contract," and directs implementers to 3.1.2 as the stable 3.1 target, which is the version the documentation pins.

Source: AdCP documentation — what's new in 3.1; AdCP GitHub releases · last verified 2026-08-18

announced A 3.2 line has begun as a pre-release: AdCP published v3.2.0-beta.0 on August 17, 2026. The project's changelog lists a promoted media-channel taxonomy, Trusted Match changes to publisher authentication and context targeting, cross-role governance enforcement, new portable and issuer-bound attestation schemas, and deprecations covering the top-level media-buy lifecycle status property, the publisher_domain filter on get_products, and inline provider credentials. It adds no eighth negotiation surface — the changes extend the seven above. The list was read from the rendered changelog rather than diffed against the schema files, and no stable 3.2 release exists yet.

Source: AdCP CHANGELOG.md; AdCP GitHub releases · last verified 2026-08-18

reported Secondary sources list curation, creative generation, and performance attribution as roadmap items still to come. Treat that list as indicative rather than current: the shipped 3.0 and 3.1 surfaces already overlap it — curation was in the v2.0.0 launch scope, 3.0 added creative workflow upgrades, and 3.1 added vendor-attested measurement — and no roadmap published by AgenticAdvertising.org was located.

Source: Adgentek glossary; The Current; AdCP documentation · last verified 2026-08-04

Adoption & ecosystem

AgenticAdvertising.org's membership is reported at between 104+ and 117+ member companies, with the figures differing by report date; the most recent secondary count, checked on August 18, 2026, gives 113+ member organizations. reported The organization publishes no count of its own: neither its About page nor its membership page states a figure, and its partner directory returned no entries when checked. Members named across secondary sources include Yahoo, PubMatic, Scope3, Samba TV, The Weather Company, Magnite, MiQ, LG Ad Solutions, Butler/Till, Raptive, and Affinity.

Source: Adgentek statistics; Samba TV; AgenticAdvertising.org — About; partner directory; PPC Land (Affinity) · last verified 2026-08-18

The organization also runs a public agent registry listing sales, creative, and signals agents that implement AdCP, filterable by agent type, status, and compliance.

Source: AgenticAdvertising.org — agent registry · last verified 2026-08-04

Deployments

The first agent-to-agent media buy was a real transaction rather than a demonstration: a Scope3 buyer agent and a Swivel seller agent transacted LG Ads programmatic inventory, with money changing hands and two humans approving. reported The date is given inconsistently — MediaPost reports the buy as executed on October 15, 2025 and shown publicly on October 16, while adcontextprotocol.org dates the execution itself to October 16.

Source: MediaPost; adcontextprotocol.org · last verified 2026-08-04

The first cross-platform agentic media buys were announced on January 6, 2026 by NBCUniversal, agency RPA, FreeWheel, and Newton Research: buy-side agents negotiated with sell-side agents over MCP across linear and digital, including live football playoff inventory for a brand's first-quarter 2026 investment — which NBCUniversal calls the first time AI agents automated live sports inventory on linear television. reported That FreeWheel built specifically an Ad Context Protocol server for the effort is a secondary-source attribution: the NBCUniversal announcement names only MCP.

Source: NBCUniversal; Adgentek statistics (the AdCP-server attribution) · last verified 2026-08-04

Four further AdCP deployments are documented, so membership is no longer the only evidence of use. PubMatic and agency Butler/Till ran an AdCP-enabled agentic connected-TV campaign for the Clubtails brand in December 2025, planned and optimized by agents without a demand-side platform workflow. Optable's Audience Agent was integrated into PubMatic AgenticOS in March 2026, positioned as an early live example of AdCP across production programmatic infrastructure. DanAds and Sigma Software launched a Sales Agent for Publishers built natively on AdCP in June 2026, with theScore and RTL AdAlliance as launch customers. And the Prebid Sales Agent — the sell-side reference implementation — states that it is built on AdCP and offers production deployment guidance.

Source: PubMatic; PPC Land; ExchangeWire; Prebid Sales Agent documentation · last verified 2026-08-04
