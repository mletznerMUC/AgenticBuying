Agent-to-agent media buy over AdCP

AdCP models a media buy as a sequence of named agent tasks rather than as a bidding exchange: a buy-side agent discovers products, creates a media buy, supplies or generates creative, and receives delivery reporting. The tasks are carried over MCP or A2A, so the same sequence works across web, mobile, connected TV, and linear inventory.

Source: AdCP GitHub repository · last verified 2026-08-04

The sequence executed in production

The first time this pattern carried a real transaction was in October 2025, when a Scope3 buyer agent and a Swivel seller agent traded LG Ads programmatic inventory for real money, with two humans approving. reported Sources place that buy on October 15 or 16, 2025.

Source: MediaPost; adcontextprotocol.org · last verified 2026-08-04

On January 6, 2026, NBCUniversal, agency RPA, FreeWheel, and Newton Research announced the first cross-platform agentic media buys running this pattern: buy-side agents negotiated with sell-side agents over MCP for a brand's first-quarter 2026 investment across linear and digital, including live football playoff inventory. reported That FreeWheel's server for the effort is specifically an Ad Context Protocol server comes from secondary coverage; the NBCUniversal announcement names only MCP.

Source: NBCUniversal; Adgentek statistics (the AdCP-server attribution) · last verified 2026-08-04

Three further deployments run variants of the same sequence: PubMatic and Butler/Till's AdCP-enabled connected-TV campaign for Clubtails, in which agents planned, executed, and optimized the buy with no demand-side platform workflow; Optable's Audience Agent inside PubMatic AgenticOS, which supplies the signals step of the sequence from publisher first-party data; and the DanAds and Sigma Software Sales Agent, which answers the discovery and buy steps for theScore and RTL AdAlliance. The set of documented endpoints is still much smaller than the membership of either standards body.

Source: PubMatic; PPC Land; ExchangeWire · last verified 2026-08-04
