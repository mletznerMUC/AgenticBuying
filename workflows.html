Agent-to-agent media buy over AdCP

AdCP models a media buy as a sequence of named agent tasks rather than as a bidding exchange: a buy-side agent discovers products, creates a media buy, supplies or generates creative, and receives delivery reporting. The tasks are carried over MCP or A2A, so the same sequence works across web, mobile, connected TV, and linear inventory.

Source: AdCP GitHub repository · last verified 2026-08-04

The sequence executed in production

On January 6, 2026, NBCUniversal, agency RPA, FreeWheel, and Newton Research announced the first cross-platform agentic media buys running this pattern: buy-side agents negotiated with sell-side agents over MCP for a brand's first-quarter 2026 investment, including live NFL playoff linear inventory. FreeWheel built an Ad Context Protocol server for the effort. Publicly confirmed production endpoints remain limited beyond this case.

Source: NBCUniversal; Adgentek statistics · last verified 2026-08-04
